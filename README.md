# Hackhive Vision

An AI-powered video intelligence system that detects, classifies, and summarizes events from video streams using open-source computer vision and vision-language models (VLMs).

### Features
- Real-time or prerecorded video processing
- Object detection and tracking
- AI-powered event summarization and classification
- Timestamped incident storage with key frames
- Natural-language querying of recorded events

### Tech Stack
Python · OpenCV · YOLO · Open-source VLMs · FastAPI · PostgreSQL

### Goal
Enable faster surveillance analysis through automated incident detection, searchable event history, and conversational querying.
